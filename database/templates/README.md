# COA Template — Distributor Alat Teknik

Template ini berisi 60 akun/heading yang sengaja dibuat cukup standar tanpa terlalu kompleks untuk distributor alat teknik.

- `coa_distributor_alat_teknik.csv`: referensi yang mudah dibuka di Excel.
- `database/seeders/DistributorTechnicalToolsCoaSeeder.php`: versi Laravel Seeder.
- Seeder hanya mengisi jika `chart_of_accounts` masih kosong, sehingga COA perusahaan existing tidak ditimpa.
